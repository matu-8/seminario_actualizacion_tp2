# Aplicacion de linea de comandos - Práctica con Arreglos

En el repositorio se encuentran dos carpetas, tp_js (correspondiente a la implementacion en lenguaje javascript), y tp_py (correspondiente a la implementación en lenguaje python)

## Requisitos

- Node.js v16 o superior
- Python 3.x

## Ejecución

### JavaScript
```bash
cd tp_js
node index.js
```

### Python
```bash
cd tp_py
python index.py
```

## Uso

Al iniciar el programa se solicitará ingresar los datos de un estudiante (nombre, edad y nota).
Una vez cargado, el sistema preguntará si se desea agregar otro estudiante respondiendo **si** o **no**.
Al finalizar la carga se mostrará:
- Lista de estudiantes en el orden de ingreso
- Lista de estudiantes ordenada por nota de mayor a menor
- Promedio general de notas
